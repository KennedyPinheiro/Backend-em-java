# Backend-em-java

##  Objetivo

Aprender e desenvolver uma estrutura de backend utilizando Java, buscando seguir os princípios de organização e arquitetura adotados pelo Spring Boot.

O projeto tem como objetivo explorar, de forma prática e gradual, a separação de responsabilidades e a organização do código em camadas, utilizando conceitos como rotas, controllers, middlewares e services.

##  Conteúdos estudados

- Fundamentos da linguagem Java.
- Lógica de programação.
- Programação Orientada a Objetos (POO).
- Organização de classes e métodos.
- Estruturação de aplicações backend.
- Separação de responsabilidades.
- Introdução à arquitetura do Spring Boot.

##  Tecnologias

- **Java** — linguagem de programação.
- **IntelliJ IDEA** — ambiente de desenvolvimento.
- **Spring Boot** — referência para os estudos de arquitetura backend.

##  Objetivo futuro

Evoluir gradualmente a estrutura desenvolvida durante os estudos, aplicando boas práticas de programação e avançando para a construção de APIs REST com Spring Boot.
