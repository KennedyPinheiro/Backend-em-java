# Atividade 1 — Cadastro e classificação de pessoas
### Objetivo: praticar variáveis, Scanner, condicionais e métodos.
Crie um programa que solicite ao usuário:
- Nome.
- Idade.
- Cidade onde mora.
- 
Depois, o programa deverá exibir os dados e informar se a pessoa é maior ou menor de idade.

Requisitos:
1. Utilize Scanner para receber os dados.
2. Crie um método chamado ehMaiorDeIdade(int idade) que retorne um boolean.
3. Crie um método chamado apresentarPessoa(String nome, int idade, String cidade) que exiba os dados.
4. Utilize uma condicional para apresentar a classificação etária.

```bash 
Exemplo de execução:
Nome: Maria
Idade: 20
Cidade: Almenara

---------- CADASTRO ----------
Nome: Maria
Idade: 20
Cidade: Almenara
Classificação: Maior de idade
------------------------------
```

**Desafio extra:** impeça que o programa aceite um nome vazio ou composto apenas por espaços.
