# Atividade 2 — Calculadora de notas
### Objetivo: praticar arrays, laços de repetição, métodos e condicionais.
Crie um programa que receba cinco notas de um aluno e calcule sua média.

Requisitos:
1. Armazene as cinco notas em um array double[].
2. Utilize um laço para receber as notas.
3. Crie um método calcularMedia(double[] notas) que retorne a média.
4. Crie um método foiAprovado(double media) que retorne true quando a média for maior ou igual a 7.0.
5. Exiba as notas, a média e a situação do aluno.


**Desafio extra:** crie métodos para identificar a maior e a menor nota.'
